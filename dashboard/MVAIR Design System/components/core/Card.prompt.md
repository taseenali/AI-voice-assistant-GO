The workhorse surface — white card with a soft, cool-tinted two-layer shadow.

```jsx
import { Card } from './Card';

<Card>KPI content…</Card>
<Card hover radius="var(--mvair-radius-lg)" padding={32}>Marketing tile</Card>
```

Default radius 12px (app); pass `--mvair-radius-lg` (18px) or `--mvair-radius-xl` (22px) for marketing. `hover` adds the −4px lift used on the landing page.
