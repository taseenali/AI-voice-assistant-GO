```text
- industry
- config_json
- created_at
```

# 🔹 2. SESSIONS TABLE (CONVERSATION TRACKING)

## 🎯 Purpose:

Track each conversation instance

---

### Schema:

```text
sessions
- id
- client_id
- current_state
- started_at
- last_active
```

---

### Why:

* Maintain session continuity
* Track user lifecycle

---

# 🔹 3. MESSAGES TABLE (CONVERSATION LOG)

## 🎯 Purpose:

Store interaction history

---

### Schema:

```text
messages

- timestamp
```

# 🔹 4. LEADS TABLE (BUSINESS OUTPUT)

### Schema:

```text
leads

- status
- created_at
```

---

### Why:

```text
analytics
```

### Why:

### Why:

* structured data

## 🔹 OPTION 2 — NoSQL (FOR SCALE)
