# Conversation Flows

## Website Flow

1. Acknowledge
2. Ask type of website
3. Ask purpose (business, portfolio, etc.)
4. Position solution
5. Move to consultation

---

## SEO Flow

1. Identify lack of traffic/leads
2. Ask current strategy
3. Highlight gap
4. Position SEO
5. Move to consultation

---

## AI Systems Flow

1. Identify inefficiency
2. Ask about processes
3. Position automation
4. Give example
5. Move to consultation

---

## App Development Flow

1. Identify idea/problem
2. Ask about functionality
3. Position solution
4. Move to consultation

---

## Rule

Each flow must:
→ diagnose
→ position
→ convert
