* normalization

Purpose:

* detect hesitation
* detect corrections
* prevent misrouting

Handles:

* “wait…”
* “hold on…”
* mid-thought changes

Behavior:

* preserves state
* overrides flow when needed

---

## 🔹 Layer 3 — Intent Router

Responsibilities:

* detect user intent
* map to correct flow
* prioritize signals

Uses:

* keyword + structured detection
* hardened regex (word boundaries fix applied)

---

## 🔹 Layer 4 — State Machine (Core Control System)

Tracks:

* conversation stage
* collected data
* flow progression

Capabilities:

* multi-step flows
* transitions between flows
* depth-based escalation
* regression when needed

---

## 🔹 Layer 5 — Response Engine (Your Strongest Asset)

Components:

### 1. Knowledge Engine

* domain-specific insights
* categorized knowledge
* metadata tagging

---

### 2. Response Builder

* assembles responses
* injects conversational boundaries
* manages phrasing variation

---

### 3. Depth System (1–5)

* controls complexity of conversation
* escalates based on engagement
* regresses when confusion detected

---

### 4. Outcome Framing

* connects features → business results
* drives value perception

---

### 5. Objection Handling System

Handles:

* price objections
* trust concerns
* hesitation
* comparison

---

## 🔹 Layer 6 — Personality System

Responsibilities:

* tone enforcement
* acknowledgment control
* response smoothing

Key Fix:

* avoids duplicate acknowledgments
* checks existing phrasing before injection

* integrations
