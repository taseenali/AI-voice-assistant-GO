\subsection{Drop (no longer own)}
\begin{itemize}
  \item \texttt{js/speech-io.js} --- browser STT/TTS loop for phone calls
  \item \texttt{server/routes/voice.js} --- TwiML ConversationRelay + WebSocket scaffold
  \item Real-time barge-in, endpointing, turn-taking, media streaming for \emph{phone}
  \item Browser-only webhook delivery dependency for phone calls
\end{itemize}

\subsection{Keep and extend}
\begin{itemize}
  \item \texttt{configs/*.json} --- per-tenant prompts, services, emergency keywords
  \item \texttt{server/routes/calendar.js} --- becomes Vapi tool endpoints
  \item \texttt{server/routes/leads.js}, \texttt{sessions.js}, \texttt{emergency.js}
  \item \texttt{js/services/webhook-dispatcher.js} pattern --- inbound from Vapi instead
  \item React dashboard, SQLite schema, multi-tenant \texttt{client\_id} routing
\end{itemize}

\section{The Two Integration Wires}

Only two HTTPS connections link your product to Vapi:

\begin{enumerate}
  \item \textbf{Configuration (you $\rightarrow$ Vapi)} --- at call start, return tenant-specific assistant config.
  \item \textbf{Callbacks (Vapi $\rightarrow$ you)} --- tool calls during the call; end-of-call transcript/recording webhook.
\end{enumerate}

\section{Step-by-Step Implementation}

\subsection{Phase A: Accounts and keys (Day 1)}
\begin{enumerate}
  \item Create Vapi org at \url{https://dashboard.vapi.ai}; obtain \texttt{VAPI\_API\_KEY}.
  \item Add to \texttt{.env}: \texttt{VAPI\_API\_KEY}, \texttt{VAPI\_WEBHOOK\_SECRET}.
  \item Provision Twilio number; in Vapi, import number (BYO Twilio) or buy via Vapi.
  \item Add provider keys in Vapi dashboard (BYOK): Deepgram STT, OpenAI/Groq LLM, ElevenLabs TTS.
  \item Sign BAAs: Vapi + Twilio + Deepgram + OpenAI + ElevenLabs (HIPAA path).
\end{enumerate}

\subsection{Phase B: New backend routes (Days 2--4)}

Create \texttt{server/routes/vapi.js} with three handlers:

\subsubsection{POST /api/vapi/assistant-request}
Triggered on inbound call. Map \texttt{call.phoneNumberId} or dialed \texttt{to} number $\rightarrow$ tenant.

\textbf{Input} (from Vapi):
\begin{verbatim}
{ "message": { "type": "assistant-request",
  "call": { "id": "...", "phoneNumber": { "number": "+1..." }}}}
\end{verbatim}

\textbf{Your logic:}
\begin{enumerate}
  \item Lookup tenant by dialed number in DB or \texttt{configs/}.
  \item Load \texttt{configs/\{client\}.json}; build system prompt from services, greetings, emergency rules.
  \item Respond within \textbf{7.5s} (telephony hard limit).
\end{enumerate}

\textbf{Output:}
\begin{verbatim}
{ "assistant": {
    "name": "Aria",
    "firstMessage": "Hi, I'm Aria at MedVoice Clinic...",
    "model": { "provider": "openai", "model": "gpt-4o-mini",
      "messages": [{ "role": "system", "content": "<tenant prompt>" }],
      "toolIds": ["tool_check_avail", "tool_book", "tool_capture_lead"] },
    "voice": { "provider": "11labs", "voiceId": "<tenant voice>" },
    "serverUrl": "https://your-domain.com/api/vapi/webhook"
}}
\end{verbatim}

\subsubsection{POST /api/vapi/webhook (tool-calls)}
\textbf{Input:}
\begin{verbatim}
{ "message": { "type": "tool-calls",
  "toolCallList": [{ "id": "toolu_xxx", "name": "check_availability",
    "arguments": { "date": "2026-06-17", "time": "10:00" }}],
  "call": { "id": "call-uuid" }}}
\end{verbatim}

\textbf{Output} (required format):
\begin{verbatim}
{ "results": [{ "toolCallId": "toolu_xxx",
    "result": "Tuesday 10:00 AM is available." }] }
\end{verbatim}

Wire tools to existing routes:
\begin{itemize}
  \item \texttt{check\_availability} $\rightarrow$ \texttt{POST /api/calendar/check}
  \item \texttt{book\_appointment} $\rightarrow$ \texttt{POST /api/calendar/book}
  \item \texttt{capture\_lead} $\rightarrow$ \texttt{POST /api/leads}
  \item \texttt{log\_emergency} $\rightarrow$ \texttt{POST /api/emergency}
\end{itemize}

Pass \texttt{client\_id} via Vapi \textbf{static parameters} (server-trusted, invisible to LLM).

\subsubsection{POST /api/vapi/webhook (end-of-call-report)}
On \texttt{message.type === "end-of-call-report"}:
\begin{itemize}
  \item Persist transcript to \texttt{sessions} + \texttt{turns} tables
  \item Store recording URL, duration, structured lead data
  \item Fire outbound webhook via server-side dispatcher (not browser)
\end{itemize}

\subsection{Phase C: Vapi tool definitions (Day 3)}
Register in Vapi dashboard or via \texttt{POST /tool}:

\begin{center}
\small
\begin{tabular}{@{}lll@{}}
\toprule
\textbf{Tool} & \textbf{Parameters} & \textbf{Server URL} \\
\midrule
\texttt{check\_availability} & date, time, duration & /api/vapi/tools/calendar-check \\
\texttt{book\_appointment} & date, time, patientName, reason & /api/vapi/tools/calendar-book \\
\texttt{capture\_lead} & name, phone, dob, insurance & /api/vapi/tools/lead \\
\texttt{transfer\_urgent} & reason & /api/vapi/tools/transfer \\

\end{center}

\subsection{Phase D: Phone routing (Day 4)}
\begin{enumerate}
  \item \texttt{PATCH /phone-number/\{id\}}: set \texttt{assistantId: null}, \texttt{server.url} = your assistant-request endpoint.
  \item Each clinic gets a dedicated Twilio number $\rightarrow$ same Vapi org, different tenant config at runtime.
  \item Test locally: \texttt{ngrok http 3001} + \texttt{vapi listen --forward-to localhost:3001/api/vapi/webhook}.
\end{enumerate}

\subsection{Phase E: Decommission custom phone orchestration (Day 5)}
\begin{enumerate}
  \item Remove ConversationRelay WebSocket scaffold from \texttt{voice.js} (keep Twilio signature middleware if needed).
  \item Keep web widget (\texttt{js/}) for demo/dashboard embed; phone traffic goes through Vapi only.
  \item Move webhook dispatch from browser IndexedDB to server-side queue for phone sessions.
\end{enumerate}

\section{Migration Safety}

Because integration = config + webhooks only, switching Vapi $\rightarrow$ LiveKit later rewrites the runtime layer only. Tool endpoints, dashboard, and tenant DB remain unchanged.

\section{Acceptance Criteria}

\begin{itemize}
  \item Inbound call to clinic number $\rightarrow$ correct tenant greeting
  \item ``Book Tuesday 10am'' $\rightarrow$ real Google Calendar freebusy + book
  \item Emergency keyword $\rightarrow$ \texttt{/api/emergency} logged + transfer offered
  \item Call end $\rightarrow$ transcript in dashboard within 30s
  \item No browser tab required for phone call processing
\end{itemize}
